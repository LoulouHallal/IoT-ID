# IoT Intrusion Detection

## Overview
This research project explores intelligent intrusion detection for Internet of Things (IoT) networks using Graph Neural Networks (GNNs) and Federated Learning (FL).

## Objectives
- Build a baseline machine learning model for IoT intrusion detection.
- Explore graph-based intrusion detection using GNNs.
- Simulate federated learning across multiple clients.
- Compare random and intelligent client-selection strategies.
- Evaluate detection performance, training time, communication cost, and convergence.

## Dataset
**CICIoT2023** — the dataset is obtained separately from the official source. The dataset files are not stored in this repository.
